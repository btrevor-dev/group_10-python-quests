# Python Adventure Quests

# Level 1: The First Incantations (Python Basics)

### Quest 1: Your First Spell
**Concept:** `print()`  
**Objective:** Print a cool welcome message.

### Quest 2: The Naming Ceremony
**Concept:** Variables  
**Objective:** Create variables for a hero's name and superpower. Print an introduction sentence.

### Quest 3: The Treasure Chest
**Concept:** Data Types  
**Objective:** Store your age (int) and favorite food (string). Print them together.

### Quest 4: The Town Crier
**Concept:** String formatting  
**Objective:** Print a dynamic message using city, year, and your name.

### Quest 5: The Echoing Cave
**Concept:** Variable reassignment  
**Objective:** Modify player health and print the final value.


# Level 2: Dialogue with the Machine (Input & Math)

### Quest 6: The Fortune Teller
**Concept:** `input()`  
**Objective:** Ask for name and quest, then print confirmation.

### Quest 7: The Magic Number Converter
**Concept:** Type conversion  
**Objective:** Convert birth year input into an integer and calculate age.

### Quest 8: The Potion Brewer
**Concept:** Arithmetic operators  
**Objective:** Calculate total cost of items.

### Quest 9: The Greedy Goblin
**Concept:** Modulo operator `%`  
**Objective:** Divide gold and determine the remainder.

### Quest 10: The Architect’s Blueprint
**Concept:** Floating-point numbers  
**Objective:** Calculate area using decimal inputs.


# Level 3: The Crossroads of Logic (Conditionals)

### Quest 11: The Guardian of the Bridge
**Concept:** `if`  
Check if the user is old enough to vote.

### Quest 12: The Two-Path Cave
**Concept:** `if-else`  
Create a password checker.

### Quest 13: The Maze of Many Choices
**Concept:** `if-elif-else`  
Build a grading system.

### Quest 14: The Logical Gatekeeper
**Concept:** Logical operators  
Check age AND gold requirements.

### Quest 15: The Nested Riddle
**Concept:** Nested `if` statements  
Create a branching mini-adventure.


# Level 4: The Power of Repetition (Loops)

### Quest 16: The Marching Ants
**Concept:** `for` loop  
Print numbers 1 to 10.

### Quest 17: The Endless Staircase
**Concept:** `while` loop  
Count from 0 to 5.

### Quest 18: The Loop of Riddles
**Concept:** While loop with user input  
Create a guessing game.

### Quest 19: The Countdown
**Concept:** `range(start, stop, step)`  
Simulate a rocket launch countdown.

### Quest 20: The Even Number Forager
**Concept:** `if` inside `for` loop  
Print even numbers from 1 to 20.


# Level 5: The Alchemist’s Lab (Functions)

### Quest 21: The Reusable Incantation
**Concept:** Defining functions  
Create and call a greeting function.

### Quest 22: The Personalized Scroll
**Concept:** Functions with parameters  
Pass user input into a function.

### Quest 23: The Oracle’s Vision
**Concept:** Returning values  
Return calculated area from a function.

### Quest 24: The Master Spell
**Concept:** Calling functions within functions  
Pass returned values between functions.


# Level 6: The Grand Challenge

### Quest 25: The Number Wizard
Enhance guessing game with high/low hints.

### Quest 26: The Simple Calculator
Build calculator using functions and conditionals.

### Quest 27: The FizzBuzz Test
Print numbers 1–100 with FizzBuzz rules.

### Quest 28: The Adventure Begins
Create a text-based adventure with multiple endings.

### Quest 29: The Code Breaker
Allow 3 attempts to guess the secret code `42`.

### Quest 30: The Reflective Scribe
Add explanatory comments to three previous scripts.


# Learning Outcomes

- Master Python fundamentals
- Understand variables, loops, conditionals, and functions
- Build interactive console programs
- Develop structured problem-solving skills
- Practice writing clean, readable code


# How to Use

1. Complete quests in order.
2. Write each solution in a separate `.py` file.
3. Test frequently.
4. Refactor older solutions as your skills improve.
5. Comment your code clearly.
